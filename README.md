# 팝써치(PopSearch)

전역 단축키로 바로 띄우는 Claude 검색창입니다. 맥의 Spotlight처럼 어디서든 단축키를 누르면 창이 뜨고, 질문하면 Claude가 답합니다.

- Windows 10/11 지원 (macOS는 공용 구조로 만들고 있으며 아직 정식 지원 전)
- [Tauri 2](https://tauri.app) 기반이라 가볍습니다 (설치 파일 약 3MB)

## 주요 기능

- **전역 단축키**(기본 `Ctrl+Shift+Space`)로 열기. 다시 누르거나 다른 곳을 클릭하면 숨고, `Esc`로 닫으면 대화가 초기화됩니다.
- **두 가지 연결 방식**
  - **CLI**: 설치된 Claude Code CLI로 질문합니다. Claude 구독(Pro/Max) 사용량을 씁니다.
  - **API**: 본인의 Anthropic API 키로 질문합니다. 쓴 만큼만 과금됩니다.(웹 검색 가능)
- **모델 선택**: 기본은 Haiku. 질문 앞에 `/s`(Sonnet), `/o`(Opus), `/h`(Haiku)를 붙이면 그 질문만 다른 모델로 보냅니다. 한/영 전환 없이 `/ㄴ` `/ㅐ` `/ㅗ`도 됩니다. 기본 모델은 설정에서 바꿀 수 있습니다.
- **결과 보기와 복사**: 마크다운과 코드 강조로 보여 줍니다. `전체 복사`와 블록별 `복사` 버튼이 있고, 복사 내용은 웹페이지를 복사할 때처럼 서식 있는 형식과 일반 텍스트가 함께 들어가 워드·엑셀·메모장에 알맞게 붙습니다. 코드 블록은 코드 본문만 복사됩니다.
- **이어서 묻기**: 한 창에서 대화가 이어집니다. 모델을 바꿔도 앞 대화를 이어받습니다.
- **히스토리**: 모든 질문과 답이 저장됩니다. `🕘` 또는 `Ctrl+H`로 검색하고 다시 열 수 있으며, 연 상태에서 질문하면 그 대화에 이어서 묻습니다. 대화를 Markdown 파일로 저장할 수 있고, 코드 울타리(```` ``` ````)가 겹쳐 깨지지 않게 자동 보정합니다.
- **첨부**: 붙여넣기(`Ctrl+V`)나 끌어다 놓기로 첨부합니다. 한 질문에 최대 5개입니다.
  - 이미지(png, jpg, gif, webp), PDF, 텍스트 파일(md, txt, csv, json, 코드 등)은 그대로 보냅니다.
  - 워드·엑셀·파워포인트·한글(`.docx` `.xlsx` `.pptx` `.hwpx`)은 앱이 글과 표만 뽑아서 보냅니다. 그림과 서식은 빠집니다.
  - `.doc` `.xls` `.hwp` 같은 예전 형식은 지원하지 않습니다.
- **선택한 텍스트 가져오기**: 다른 앱에서 글을 선택한 채 단축키를 누르면 그 글이 입력창에 들어갑니다. 글과 그림을 함께 선택하면 그림도 첨부됩니다. ([아래 주의 사항](#선택한-텍스트-가져오기에-대해) 참고)
- **로그인 시 자동 실행** (설정에서 끌 수 있음)

## 필요한 것

### WebView2 런타임 (Windows)

팝써는 화면을 그리는 데 Microsoft **WebView2 런타임**을 씁니다.

- **Windows 11**: 기본 포함되어 있습니다.
- **Windows 10**: 대부분 Edge와 함께 이미 설치되어 있습니다. 다만 LTSC 판이나 Edge를 제거한 PC에는 없을 수 있습니다.
- **설치 여부 확인**: 앱을 실행했는데 창이 뜨지 않거나 WebView2 관련 오류가 나면 없는 것입니다. 이때는 [Microsoft WebView2 다운로드 페이지](https://developer.microsoft.com/microsoft-edge/webview2/)에서 **Evergreen Bootstrapper**를 받아 설치하세요.
- **설치 파일(`-setup.exe`) 사용 시**: WebView2가 없으면 설치 과정에서 자동으로 내려받습니다. 인터넷 연결이 필요합니다.

### CLI 방식을 쓸 때

- [Claude Code](https://docs.claude.com/en/docs/claude-code) CLI를 설치하고 한 번 로그인해 두어야 합니다.
  ```
  npm install -g @anthropic-ai/claude-code
  claude
  ```
  (`claude`를 처음 실행하면 로그인 안내가 나옵니다.)
- 팝써치는 `PATH`에서 `claude.exe`를 찾습니다. npm으로 설치했다면 자동으로 찾습니다. 다른 곳에 있다면 환경 변수 `POPSEARCH_CLAUDE_BIN`에 `claude.exe`의 전체 경로를 지정하세요.
- 질문은 구독의 사용 한도에서 차감됩니다. Claude Code로 하는 다른 작업과 한도를 함께 씁니다.

### API 방식을 쓸 때

- [Claude 개발자 플랫폼](https://platform.claude.com)에서 API 키를 발급받고 크레딧을 충전하세요. 선불이며 최소 $5입니다.
- 팝써치 설정(`F5`)에서 공급자를 **API**로 바꾸고 키를 붙여넣은 뒤 `저장`을 누르세요.
- API 방식에서만 **웹 검색**을 켤 수 있습니다. 검색 비용이 별도로 붙습니다.

## 설치

둘 중 하나를 고르세요.

| 방식 | 파일 | 특징 |
|---|---|---|
| 설치 파일 | `PopSearch_<버전>_x64-setup.exe` | 내 계정에만 설치(관리자 권한 불필요). 시작 메뉴·제거 항목 생성 |
| 실행 파일만 | `popsearch.exe` | 설치 없이 실행. 고정된 폴더(예: `C:\Tools\PopSearch\`)에 두고 쓰세요 |

실행 파일만 쓸 때는 **처음 실행한 위치로 자동 실행이 등록**됩니다. 나중에 파일을 옮겼다면 옮긴 위치에서 한 번 실행한 뒤, 설정의 자동 실행을 껐다 켜서 경로를 다시 등록하세요.

실행하면 트레이(작업 표시줄 오른쪽 아래)에 아이콘이 생기고 창은 숨어 있습니다. 단축키로 여세요. 트레이 아이콘을 눌러도 열 수 있습니다.

## 사용법

| 키 | 동작 |
|---|---|
| `Ctrl+Shift+Space` | 열기 / 숨기기 (설정에서 변경) |
| `Enter` | 질문 보내기 |
| `Shift+Enter` | 줄바꿈 |
| `Esc` | 열린 패널 닫기 → 한 번 더 누르면 대화 초기화 후 숨기기 |
| `F5` | 설정 |
| `Ctrl+H` | 히스토리 |
| `/s` `/o` `/h` (`/ㄴ` `/ㅐ` `/ㅗ`) + 공백 | 이번 질문만 Sonnet / Opus / Haiku |

입력창 오른쪽의 모델 표시를 보면 다음 질문이 어느 모델로 가는지 알 수 있습니다.

### 선택한 텍스트 가져오기에 대해

1. 먼저 Windows 접근성 기능(UI Automation)으로 선택된 글을 직접 읽습니다. 이 단계에서는 **클립보드를 건드리지 않습니다.**
2. 그렇게 읽을 수 없는 앱이거나 그림을 함께 가져와야 할 때는, 앱이 `Ctrl+C`를 대신 눌러 복사합니다. 복사한 뒤 **원래 클립보드 내용으로 되돌립니다.** 클립보드 백업에 실패하면 아무 키도 보내지 않습니다.
3. 터미널과 코드 에디터에서는 `Ctrl+C`가 "실행 중지"나 "현재 줄 복사"로 동작할 수 있어서 2번을 하지 않습니다. 대상은 Windows Terminal, 명령 프롬프트, PowerShell, Git Bash, VS Code, Cursor, JetBrains 계열 등이며, 목록은 `src-tauri/src/selection.rs`에 있습니다.
4. 섞인 선택에 포함된 웹 이미지는 이미지 주소에서 내려받아 첨부합니다. 첨부된 것은 보내기 전에 ✕로 뺄 수 있습니다.

이 기능이 필요 없다면 설정에서 `단축키로 열 때 선택한 텍스트 가져오기`를 끄세요.

## 데이터와 개인정보

| 항목 | 저장 위치 |
|---|---|
| 설정 | `%APPDATA%\com.popsearch.app\settings.json` |
| 히스토리 | `%APPDATA%\com.popsearch.app\history.db` (SQLite) |
| API 키 | Windows 자격 증명 관리자 (`PopSearch` 항목). 파일로 저장하지 않습니다 |

- 질문, 첨부 파일, 이어서 묻기용 이전 대화는 선택한 방식에 따라 Anthropic으로 전송됩니다. CLI 방식은 Claude Code를 거치고, API 방식은 Anthropic API로 바로 갑니다.
- 히스토리에는 이미지 축소본과 첨부 파일 이름만 저장되고, 파일 내용은 저장되지 않습니다.
- 앱을 지워도 위 데이터는 남습니다. 완전히 지우려면 `%APPDATA%\com.popsearch.app` 폴더와 자격 증명 관리자의 `PopSearch` 항목을 삭제하세요.

## 알려진 제한

- **macOS**: 공용 구조로 만들었지만 아직 맥에서 빌드·테스트하지 않았습니다. 맥에서는 선택 텍스트를 `Cmd+C`로만 가져오고 클립보드를 되돌리지 않습니다.
- **워드·엑셀 등**: 텍스트와 표만 전달합니다. 문서 속 그림, 차트, 서식은 빠집니다.
- **CLI 방식**: 모델마다 별도 프로세스를 쓰므로, 처음 쓰는 모델은 첫 응답이 1~2초 늦습니다.
- **기록에서 이어서 묻기**: 이전 대화를 텍스트로 함께 보내므로, 이전 대화의 이미지는 "(이미지 첨부됨)"이라는 표시로만 전달됩니다.

## 소스에서 빌드하기

필요한 것: Node.js 20 이상, Rust(stable, MSVC), Visual Studio 2022 Build Tools(C++ 워크로드), WebView2 런타임.

```
npm install
npm run tauri dev      # 개발 모드 (코드 수정 시 자동 반영)
npm run tauri build    # 설치 파일 생성 → src-tauri/target/release/bundle/nsis/
```

- 테스트: `cargo test --manifest-path src-tauri/Cargo.toml`
- 개발 모드에서는 자동 실행 설정이 OS에 적용되지 않습니다(설치본에서만 적용).
- 설계 문서는 [SPEC.md](SPEC.md), 작업 기록은 [orders/](orders/)에 있습니다.
