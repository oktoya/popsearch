## 요약
한글 조합 중(글자 밑줄 상태)에 `Alt+Enter`(맥은 `Cmd+Enter`도)를 누르면 아무 일도 일어나지 않아, 띄어쓰기·화살표로 조합을 끝낸 뒤 다시 눌러야 했다. 조합 중에 눌러도 조합 중이던 글자까지 확정한 뒤 바로 웹 검색으로 보내도록 고친다. (Windows 사용자 요청, 맥에도 같은 문제가 있을 수 있어 함께 적용)

## Order 1
Target files: `src/main.ts`, `SPEC.md`, `README.md`

### Background
The send handler is the second `input.addEventListener("keydown", ...)` in `src/main.ts` (~line 817):
```ts
  if (e.key !== "Enter") return;
  if (e.isComposing || e.keyCode === 229) return;
  if (e.shiftKey) return;
  e.preventDefault();
  ...
  const forceWeb = e.altKey || (IS_MAC && e.metaKey);
```
While a Korean syllable is being composed, the Enter keydown arrives with `isComposing === true` and/or `keyCode === 229` (on Windows `e.key` is often `"Process"` instead of `"Enter"`; use `e.code === "Enter" || e.code === "NumpadEnter"` to recognize the physical key). The handler returns early, so Alt+Enter does nothing. The guard exists so a plain Enter that only commits the IME composition does not send twice — plain Enter behavior must NOT change.

### Changes
1. `src/main.ts` — "send after composition" for the web-search modifier only:
   - Extract the body that runs after the guards (parse, empty check, history-continue branch, `send(...)`) into a function, e.g. `submitQuery(forceWeb: boolean)`, and call it from the existing path unchanged.
   - In the keydown handler, when the physical key is Enter (`e.key === "Enter" || e.code === "Enter" || e.code === "NumpadEnter"`), the event is composing (`e.isComposing || e.keyCode === 229`), `!e.shiftKey`, and the web modifier is held (`e.altKey || (IS_MAC && e.metaKey)`): call `e.preventDefault()` and set a pending flag (e.g. `pendingWebSend = true`). Do not send yet.
   - Add an `input` `compositionend` listener: if `pendingWebSend`, clear it and call `submitQuery(true)` on the next tick (`setTimeout(..., 0)`) so `input.value` already contains the committed syllable.
   - Fallback: if no `compositionend` arrives within ~150 ms after setting the flag (some IMEs commit without it, e.g. composition already ended by the Alt key), clear the flag and call `submitQuery(true)` if the composition is no longer active. Make sure the query is sent exactly once (no double send if both paths fire).
   - Clear `pendingWebSend` when the input is cleared/reset or when a new composition starts (`compositionstart`) so a stale flag never fires later.
   - Plain Enter during composition (no modifier) keeps today's behavior exactly.
2. `SPEC.md` — in the 웹 검색 row, after the Alt+Enter sentence, add in Korean: 한글 조합 중에 눌러도 조합 중인 글자를 확정한 뒤 바로 웹 검색으로 보냄.
3. `README.md` — in the shortcut table `Alt+Enter` row, add in Korean that it works even while a Korean syllable is being composed (the composing character is committed first). Keep the macOS note; adjust it so it doesn't contradict (Option+Enter on macOS is still taken by the Korean IME's 한자 변환 while composing, so Cmd+Enter remains recommended there).

  - 폴백이 imeComposing 대신 e.isComposing만 믿는 게 아니므로 Windows에서 Alt 때문에 조합이 먼저 끝난 경우도 처리됨. 실기기(Windows 한글, macOS Cmd+Enter) 확인은 사용자 GUI 테스트 필요.
