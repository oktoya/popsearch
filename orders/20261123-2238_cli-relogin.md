# 20261123-2238_cli-relogin

Power: mid

## 요약
CLI 방식에서 Claude Code 로그인이 만료되면 영어 오류만 나와서 사용자가 터미널을 열고 `claude auth login`을 직접 쳐야 했다. 로그인 오류를 감지하면 한국어 안내와 [다시 로그인] 버튼을 보여 주고, 버튼을 누르면 팝써치가 `claude auth login`을 대신 실행해 브라우저를 연다. 로그인이 끝나면 상주 CLI 세션을 새로 띄워 바로 다시 질문할 수 있게 한다.

## Order 1
Target files: `src-tauri/src/provider_cli.rs`, `src-tauri/src/lib.rs`, `src/main.ts`, `src/styles.css`, `SPEC.md`, `README.md`

### Background
- CLI errors reach the frontend via the `popsearch://error` event → `onError(message)` in `src/main.ts` (~line 713), which puts the raw message into `currentAnswer` with class `error`.
- Example expired-login message: `Failed to authenticate: this login reached its time limit and cannot be renewed. Run \`claude auth login\` to sign in again, or use \`claude setup-token\` and set CLAUDE_CODE_OAUTH_TOKEN for unattended jobs`.
- `claude auth login` (Claude Code 2.1.x) opens a browser for sign-in; options: `--claudeai` (default), `--console`, `--email`, `--sso`. `claude auth status --json` prints JSON with `"loggedIn": true|false`.
- `provider_cli::find_claude_bin()` locates the binary; `CliSession::spawn` shows how to spawn without a console window on Windows (`creation_flags(0x08000000)`). `Manager::reset_sessions(app)` kills and re-warms all CLI sessions; exposed as the `reset_cli_sessions` command.
- The main window hides on focus loss (by design). When the browser opens, the window will hide; that's fine — the DOM keeps its state, and the user sees the result when reopening.

### Changes
1. `src-tauri/src/provider_cli.rs` — add:
   - `pub fn is_auth_error(msg: &str) -> bool` — case-insensitive match on any of: `failed to authenticate`, `auth login`, `/login`, `not logged in`, `oauth token`, `authentication_error`, `invalid api key`. Unit-test it (expired message above → true; `"boom"`, a network error text → false).
   - `pub fn run_login(app: &AppHandle) -> Result<(), String>` (blocking; called from an async command via `tauri::async_runtime::spawn_blocking` or similar):
     - Spawn `<claude> auth login` with stdin = null, stdout/stderr piped, current dir = temp dir, `creation_flags(0x08000000)` on Windows.
     - Read stdout and stderr lines on threads; the first `https://` URL seen in either stream → emit `popsearch://login-url` with `{ "url": "<url>" }` (do NOT open it yourself; the CLI opens the browser — the URL is only a fallback link for the UI).
     - Wait up to 5 minutes; on timeout kill the child and return `Err` with a Korean message telling the user to run `claude auth login` in a terminal.
     - After exit, run `<claude> auth status --json` (same spawn flags, 15 s timeout) and parse `loggedIn`. If true → `Ok(())`; otherwise `Err` with a Korean message including a short tail (≤ 300 chars) of the login process output, and the terminal fallback hint.
     - If the binary is not found → `Err(NOT_FOUND_MSG)`.
     - Never log or emit tokens; only the first https URL and short output tails.
   - Guard against concurrent runs with a static `AtomicBool` (second call returns `Err("이미 로그인 진행 중입니다.")`).
2. `src-tauri/src/lib.rs` — add an async command `cli_login(app, manager)` that runs `run_login` off the main thread, and on `Ok` calls `manager.reset_sessions(&app)`; returns `Result<(), String>`. Add an `is_auth_error`-based command is NOT needed — detection is done in the frontend (see 3). Register `cli_login` in `generate_handler!`.
3. `src/main.ts` — in `onError(message)`: if the current provider is CLI and the message matches the same patterns (implement a TS `isAuthError` mirroring the Rust list), render instead of the raw text:
   - Korean line: `Claude Code 로그인이 만료되었거나 필요합니다.`
   - A button `다시 로그인` (use `document.createElement`, no innerHTML with user text). On click: disable the button, show `브라우저에서 로그인을 마치세요… (창이 닫혀도 계속 진행됩니다)`, `await invoke("cli_login")`.
     - Success → replace with `로그인되었습니다. 다시 질문하세요.` and re-enable the input.
     - Failure → show the returned Korean error text.
   - While waiting, listen for `popsearch://login-url`; when received, show a small link `브라우저가 열리지 않으면 여기를 누르세요` that opens the URL with the existing `openUrl`.
   - Keep a collapsed/small copy of the original English message under the button (e.g. a `<details>` with summary `원래 오류`) for debugging.
   - Find how the frontend knows the current provider (settings) and reuse it; if the provider is API, keep today's behavior.
4. `src/styles.css` — minimal styles for the login button/link inside `.answer.error` (reuse existing button look if one exists, e.g. copy buttons).
5. `SPEC.md` — add a short Korean note (CLI 공급자 section or 인증 row): CLI 로그인 오류를 감지하면 [다시 로그인] 버튼으로 `claude auth login`을 대신 실행(브라우저 로그인), 완료 후 `claude auth status`로 확인하고 CLI 세션 재시작. 브라우저에 코드 붙여넣기를 요구하는 환경이면 5분 제한 후 터미널 안내.
6. `README.md` — in the CLI 방식 section, one Korean bullet: 로그인이 만료되면 팝써치 창의 [다시 로그인] 버튼으로 브라우저 로그인을 할 수 있음.
