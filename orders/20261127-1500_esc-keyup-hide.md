## 요약
- 증상: 유튜브 전체화면 위에서 팝써치를 띄웠다가 Esc로 닫으면 브라우저 전체화면이 풀림(Firefox·Chrome).
- 1단계 재현(Firefox 테스트 페이지, 실제 C:\apps 앱): Esc를 0.08초 누르면 정상, **0.3초 누르면 창이 숨은 뒤 브라우저가 Esc 떼기를 받아 전체화면 해제**(페이지에는 Esc 이벤트가 오지 않음 = 브라우저 자체 처리). 팝써치는 Esc **keydown**에서 창을 숨기므로, 아직 눌린 Esc의 keyup이 뒤 창으로 간다. 예전 스페이스 문제와 같은 종류.
- 수정: 창을 숨기는 Esc는 keydown이 아니라 **keyup**에서 숨긴다. 그러면 떼기까지 팝써치가 받은 뒤 창이 사라진다. 설정·히스토리 패널 닫기(Esc)는 지금처럼 keydown.

## Order 1
Target files: `src/main.ts`

### Background
`src/main.ts` window keydown handler (~line 1035): on `Escape`, it closes the settings panel or history panel if open (return), otherwise `await resetAll(); invoke("hide_window");`. Hiding on keydown lets the still-held Escape's keyup reach the browser behind, which exits fullscreen.

### Changes
1. In the Escape branch of the window keydown handler: keep `e.preventDefault()` and the panel-close paths unchanged. For the hide path, do NOT hide on keydown. Instead set a flag (e.g. `escHidePending = true`) and return. Ignore `e.repeat` keydowns (they must not re-trigger anything; keep preventDefault).
2. Add a `window` `keyup` listener: if `e.key === "Escape"` and `escHidePending`, clear the flag, `e.preventDefault()`, then run the existing hide sequence (`await resetAll(); invoke("hide_window");`).
3. Clear `escHidePending` when the window loses focus (`window` `blur`) so a stale flag cannot hide the window later.
4. If there is an existing `keyup` listener on window (the Ctrl+H fallback), add a separate listener or extend carefully; do not change the Ctrl+H behavior.
5. Respect `capturingHotkey` the same way the keydown handler does (if capturing a hotkey in settings, Escape is handled there; do not hide).

### Constraints
- Do not modify, create, or delete any file not listed above.
- Never rewrite or regenerate a whole file; targeted edits only.
- Other shortcuts and the Esc-closes-panel behavior unchanged.
- Do not run the app.

### Done when
- `npm run build` passes.
- Code trace: Esc with no panel open hides only on keyup, once; Esc with a panel open closes the panel on keydown and the following keyup does nothing; holding Esc (repeat) does nothing extra.
