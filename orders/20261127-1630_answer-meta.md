3. **Types (`history.ts`)**: `HistoryMessage` gets `web: boolean`.
4. **Display (`main.ts`, `styles.css`)**:
   - Replace the current question-bubble model badge (`model-badge`, shown only for Sonnet/Opus in `buildQuestion`) with a small gray meta line placed directly above each answer: text `Haiku`, `Sonnet`, or `Opus`, followed by ` · 🌐 웹 검색` when web was on. Show it for every model, including Haiku.

   - History view / reopened conversations (`renderMessages`): use each message's `model` and `web`.
